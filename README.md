A TOML Driver for Laravel Paper

## Installation

You can install the package via Composer:

```bash
composer require thecodechef/laravel-paper-toml-driver
```

You may publish all of the package's resources at once:

```bash
php artisan vendor:publish --tag="laravel-paper-toml-driver"
```

Or, you may publish each resource individually:

### Publishing the Configuration File

```bash
php artisan vendor:publish --tag="laravel-paper-toml-driver-config"
```

### Publishing and Running the Migrations

```bash
php artisan vendor:publish --tag="laravel-paper-toml-driver-migrations"
php artisan migrate
```

### Publishing the Views

```bash
php artisan vendor:publish --tag="laravel-paper-toml-driver-views"
```

### Publishing the Translations

```bash
php artisan vendor:publish --tag="laravel-paper-toml-driver-lang"
```

### Publishing the Public Assets

```bash
php artisan vendor:publish --tag="laravel-paper-toml-driver-assets"
```
